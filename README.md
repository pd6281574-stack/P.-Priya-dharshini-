# LegalEase

## 📌 About
LegalEase is a Generative AI-powered application that helps users create legal documents easily using customizable templates.

## 🚀 Features
- Generate legal documents
- Customizable document templates
- Easy and user-friendly interface
- Editable legal documents
- Supports different types of legal documents

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI
- AI: Generative AI
- Database: MySQL / MongoDB

## 📄 Documents
- Employment Contracts
- Lease Agreements
- Non-Disclosure Agreements (NDA)
- Other legal documents

## 🎯 Objective
To simplify the process of creating professional legal documents by providing customizable and easy-to-use AI-powered templates.

LegalEase – AI-Powered Legal Document Generator
